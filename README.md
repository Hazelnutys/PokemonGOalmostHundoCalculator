Pokemon GO Stat Calculator

포켓몬고(Pokémon GO) 포켓몬의 스탯(공격, 방어, 체력)과 CP를 개체값(IV) 및 레벨에 따라 간편하게 계산하고 비교할 수 있는 웹 기반 도구입니다.

기능

포켓몬 검색 및 종족값 자동 불러오기

포켓몬 이름이나 번호로 간편하게 검색

1세대부터 최신 세대까지 지원되는 종족값(Base Stats) 데이터 탑재

스탯 및 CP 계산

공격(Atk), 방어(Def), 체력(HP) 개체값(0~15) 조절 가능

Lv 50, 베스트 파트너 Lv 51 지원

스탯 곱(Stat Product) 및 효율성 퍼센티지 표시

유사백 확인

HP 개체값이 14이더라도 15와 실제 체력(HP) 수치가 동일한 구간을 자동으로 판별해 하이라이트

🛠️ 기술 스택

Frontend: HTML5, CSS3, JavaScript (ES6+)

Styling: Tailwind CSS (CDN 사용 권장)

Deployment: Static Web Hosting (GitHub Pages, Vercel 등)
